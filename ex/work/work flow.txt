회원가입 입력값 정규표현식 검사 실습문제

HTML, CSS, JavaScript를 사용하여 회원가입 입력 검사 화면을 만드시오.

사용자는 다음 정보를 입력할 수 있어야 한다.

아이디
비밀번호
이메일
이름

각 입력칸은 사용자가 입력할 때마다 JavaScript 정규표현식으로 검사해야 하며, 입력칸 아래에 검사 결과 문장이 바로 출력되어야 한다.

기능 조건
1. 아이디 검사

조건:

영문 소문자와 숫자만 사용 가능
5자 이상 12자 이하

정규식 예시:

/^[a-z0-9]{5,12}$/

성공 메시지:

사용 가능한 아이디입니다.

실패 메시지:

아이디는 영문 소문자와 숫자만 사용하여 5~12자로 입력하세요.
2. 비밀번호 검사

조건:

영문 포함
숫자 포함
특수문자 포함
8자 이상 16자 이하

허용 특수문자:

! @ # $ % ^ & *

정규식 예시:

/^(?=.*[A-Za-z])(?=.*\d)(?=.*[!@#$%^&*])[A-Za-z\d!@#$%^&*]{8,16}$/

성공 메시지:

사용 가능한 비밀번호입니다.

실패 메시지:

비밀번호는 영문, 숫자, 특수문자를 포함하여 8~16자로 입력하세요.
3. 이메일 검사

조건:

이메일 형식으로 입력
예: test@gmail.com

정규식 예시:

/^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$/

성공 메시지:

올바른 이메일 형식입니다.

실패 메시지:

이메일 형식이 올바르지 않습니다.
4. 이름 검사

조건:

한글만 입력 가능
2자 이상 5자 이하

정규식 예시:

/^[가-힣]{2,5}$/

성공 메시지:

올바른 이름입니다.

실패 메시지:

이름은 한글 2~5자로 입력하세요.
스타일 조건
전체 화면은 가운데 정렬한다.
회원가입 박스는 흰색 배경으로 만든다.
입력칸은 세로로 배치한다.
검사 성공 메시지는 초록색으로 표시한다.
검사 실패 메시지는 빨간색으로 표시한다.
입력칸에는 padding과 border-radius를 적용한다.
버튼에는 hover 효과를 적용한다.
