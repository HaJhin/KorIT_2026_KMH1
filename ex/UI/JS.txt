document객체가 필요한 이유
- JavaScript는 HTML을 직접 수정할 수 없다
- 반드시 document를 통해 접근을 해야 한다.

<h1 id="title">안녕하세요</h1>

- CSS 선택자로 태그를 선택하는 방법도 있음

document 객체가 하는 일
- HTML 요소 찾기
- 글자 변경
- 이미지 변경
- CSS 변경
- 새로운 태그 생성
- 태그 삭제
등을 할 수 있다.

document의 대표적인 메서드
document.write() -> 문서에 글자를 출력한다.
※ body에 있는 내용은 지우고 출력을 하기 때문에 실무에서 많이 쓰지 않는다.

document.createElement() -> 새로운 태그를 만든다.(만드는 역할만 한다.)

document.body -> 웹페이지의 body에 접근을 한다.

body.appendChild(요소); -> 부모 요소의 마지막 자식으로 새로운 요소를 추가하겠다.

꼭 body가 아니라 내가 js로 선택한 태그의 자식으로도 추가할 수 있다.

변수(Variable)
변수선언을 할 때 var, let, const와 같은 키워드를 사용한다.

var : 예전에 사용하던 변수 선언 키워드
- 같은 변수명으로 재선언도 가능하다.
- 대입이 가능하다.
- 같은 이름의 변수를 실수로 여러번 만들어도 오류가 발생하지 않아서 버그가 생기기 쉽다.

let : 값이 변경될 수 있는 변수를 선언하는 키워드
let 변수명 = 값;
- 대입은 가능하다.
- 같은 변수명으로 재선언하는 것은 불가능하다.

const : 값이 변경되지 않는 상수를 선언하는 키워드
- 상수를 선언할 때 값을 초기화해야 한다.
- 대입을 할 수 없다
- 같은 이름으로 재선언을 할 수 없다.
- 변하면 안되는 값을 저장할 때 사용한다.

배열
- 여러개의 데이터를 한번에 보관할 수 있는 자료구조

배열의 생성 방법
1. [] : 리터럴을 사용하는 방법
2. Array(), new Array() 생성자를 이용하는 방법
ㄴ 길이를 지정할 수 있다.
ㄴ 매개변수 자리에 여러개의 값을 넣거나, 문자열을 넣으면 요소로 포함하는 배열을 생성

js배열의 특징
- 다양한 타입을 하나의 배열에 요소로 넣을 수 있다.
[100, 3.14, '문자열', true, [1,2,3]]

- 길이의 제한이 따로 없어서 넣는만큼 들어간다.

- 리터럴로 만들면 length가 0이다.
- 생성자를 통해서 초기 길이를 지정하면 공간만큼 empty가 들어가있다.

객체(object)
- 관련된 데이터와 동작을 하나로 묶은 데이터 구조다.

객체의 생서
js에서는 클래스 없이 객체를 만드는 것이 가능하다.

1. 객체 리터럴 생성 방식

let 객체명 = {};

- 프로퍼티(property) : 객체 안에 들어가는 대이터
ㄴ 프로퍼티의 구조 -> 키(key) : 값(value)

let user = {
	name : "홍길동",
	age : 30,
	address : "인천"
	introduce : function() { 실행하고자 하는 코드; }
	introduce() { 실행하고자 하는 코드
}

객체 안의 있는 속성값을 가져오거나 메서드를 실행하는 방법
객체명.속성명 -> 값을 가져올 수 있다.
객체명["속성명"]

객체명.메서드명();

생성자 함수를 이용하여 객체 만들기
js는 메서드 말고 독립적으로 호출하는 함수가 존재하기 때문에 가능하다.
function Student(){
	this.name = name;
	this.age = age;
	this.address = address;
}

let S1 = new Student('홍길동',20,'인천시');

클래스를 통한 객체 생성
- 여러개의 객체를 만들 때 편하다
class Member{
	constructor(name,age){
		this.name = name;
		this.age = age;
	}
}

let m1 = new Member('홍길동',20);
let m2 = new Member('김길동',30);

함수
자주 사용하는 코드들의 묶음

function 함수명(매개변수){ ... };

함수명();

함수표현식
const 함수명 = function(매개변수) { ... };

함수명();

화살표함수
(매개변수) => { ... };

매개변수가 없으면 소괄호 생략 불가능
1개일 때는 생략 가능
2개일 때는 생략 불가능

명령이 한줄일 때는 중괄호 생략 가능
return이 있으면 키워드와 함께 중괄호 생략이 가능하다.

객체 안에 들어가는 메서드는 화살표함수를 쓰지 않는다.

let user = {
	name : '홍길동'
	sayHello(){
		console.log(this.name);
	}
	or
	sayHello : () => {console.log(this.name)
}

user.sayHello();

일반함수의 this
- 누가 호출했는지를 보고 this를 결정한다.

화살표 함수의 this
- 자기만의 this가 없다
- 대신 바깥(this)을 그대로 가져온다.

dom 요소의 선택
1. getElementById("아이디값") : 아이디를 이용한 선택

2. querySelector("CSS 선택자") : CSS 선택자를 이용한 선택
ㄴ 중복되는 값이 있으면 첫번째만 선택

3. querySelectorAll("CSS 선택자") : 전부다 선택 배열처럼 index를 활용하여 각 요소를 선택할 수 있다.

선택한 dom 요소를 조작하기
1. attribute 조작하기
- hasAttribute() : 속성을 가지고 있는지 검사
- getAttribute() : 속성값을 반환
- setAttribute() : 속성을 세팅
- attributes : 태그가 가지고 있는 모든 속성을 가져온다.
- removeAttribute() : 속성을 제거

DOM 객체의 스타일 변경하기
- 선택한 요소객체의 style 프로퍼티를 이용하여 변경하기
let element = document.getElementById("myElement");

element.style.스타일속성 = "값";

스타일속성은 카멜표현식으로 작성

classList 프로퍼티
html요소의 class 속성을 자바스크립트로 추가, 삭제, 변경할때 사용하는 프로퍼티이다.

element.classList -> 요소의 class 목록을 가져온다.

element.classList.add("클래스명1","클래스명2") : 클래스를 추가

element.classList.remove("클래스명") : 요소에서 클래스값을 삭제
element.classList.contains("클래스명") : 요소가 해당 클래스 값을 가지고 있는지 검사
element.classList.toggle("클래스값") : 있으면 삭제, 없으면 주차
element.classList.replace("기존값","바꾸려는 값") : 클래스를 교체할 수 있다.
