이메일 조건

이메일은 직접 전체를 입력하는 것이 아니라 다음 형태로 작성한다.

이메일 아이디 @ 도메인 선택

예시:

hong @ gmail.com

저장될 이메일:

hong@gmail.com
도메인 select 항목

다음 항목을 포함하시오.

<option value="gmail.com">gmail.com</option>
<option value="naver.com">naver.com</option>
<option value="daum.net">daum.net</option>
<option value="kakao.com">kakao.com</option>

JavaScript 요구사항
1) 회원 저장 배열

회원 정보를 저장할 배열을 만든다.

let members = [];

회원 한 명은 다음과 같은 객체 형태로 저장한다.

{
    id: "user01",
    pw: "1234",
    email: "user01@gmail.com"
}
2) 아이디 중복검사 기능

중복검사 버튼을 클릭하면 다음 조건에 따라 처리한다.

조건   처리
아이디를 입력하지 않은 경우   아이디를 입력하세요. alert 출력
이미 같은 아이디가 있는 경우   이미 사용 중인 아이디입니다. 메시지 출력
중복이 없는 경우   사용 가능한 아이디입니다. 메시지 출력
3) 회원가입 기능

회원가입 버튼을 클릭하면 다음 조건에 따라 처리한다.

조건   처리
아이디, 비밀번호, 이메일 아이디 중 하나라도 비어 있음   모든 항목을 입력하세요. alert 출력
이미 가입된 아이디   이미 가입된 아이디입니다. alert 출력
모든 조건 통과   회원 객체를 배열에 저장
4) 회원가입 완료 후 처리

회원가입이 완료되면 다음 작업을 수행한다.

회원가입이 완료되었습니다. 메시지 출력
아이디 입력창 비우기
비밀번호 입력창 비우기
이메일 아이디 입력창 비우기
회원 목록 다시 출력하기
5) 회원 목록 출력 조건

회원 목록에는 다음 정보만 출력한다.

아이디
이메일

비밀번호는 출력하지 않는다.
