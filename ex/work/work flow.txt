GitHub 사용자 프로필 검색

사용 API
https://api.github.com/users/사용자아이디

GitHub 아이디를 입력하면 사용자 프로필 정보를 조회한다.

HTML 조건
요소   조건
아이디 입력   input id="githubId"
검색 버튼   button id="searchBtn"
오류 메시지   p id="message"
결과 영역   div id="profileBox"

JS 유효성검사 조건
검사 항목   조건
빈 값   검색 불가
길이   3자 이상 20자 이하
허용 문자   영어, 숫자, 하이픈만 허용
하이픈 위치   처음과 끝에는 하이픈 불가
사용자 없음   “존재하지 않는 사용자입니다” 출력
API 제한 오류   “잠시 후 다시 시도하세요” 출력

출력 조건
프로필 이미지
아이디
이름
소개
팔로워 수
팔로잉 수
공개 저장소 수
GitHub 페이지 링크

필수 JS 조건
response.ok 검사
정규식
조건문
