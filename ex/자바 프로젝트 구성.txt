src 폴더
- 소스코드가 저장되는 폴더
- 패키지 단위로 폴더가 만들어지고, 그 안에 파일이 위치한다.
- 작성하는 모든 파일은 이곳에 저장된다.
JRE System Library
- 프로젝트 실행에 필요한 코드들의 묶음
- 기본적인 기능이 들어있다.
- 프로젝트 생성 시 자동으로 추가된다.
Package
- 관련있는 클래스끼리 묶어놓는 폴더 개념
- src 폴더 안에 하위 폴더로 생성됨.
Class
- 자바 프로그램의 기본 구성 단위이다.
- 자바에서 모든 코드는 반드시 클래스 블록( {} ) 안에 있어야 한다.
Method
- 클래스 안에서 정의된 함수

정수 -> 문자
실수를 정수로 바꿀 때 소수점 아래 값은 소실된다.
자바코드 -> 바이트코드 -> JVM이 실행 -> 결과가 출력

자바는 실행성능을 향상 시키기 위해 컴파일 과정을 거친다.

형변환(타입변환)

강제형변환(명시적형변환)

객체지향 프로그래밍(object-oriented Programming)
- 프로그램을 객체 단위로 나눠 설계하고 구현하는 방식		

객체지향을 사용하지 않을 때 문제점
- 데이터와 기능이 따로 논다
- 코드가 많아지게 되면 관리가 어렵다
- 재사용이 힘들다

객체지향의 핵심 개념
1. 클래스
-설계도
- 필드
ㄴ 객체의 정보
메서드
ㄴ 객체의 동작		

2. 객체
클래스명 객체변수명 = new 클래스명();
객체변수명.필드명
- 클래스에 정의된 기능을 호출하여 사용 가능

3. 객체지향의 4가지 개념
- 캡슐화
데이터를 보호하는 개념
필드에 직접 접근하지 못하도록 만든다.
제공된 메서드를 통해 필드에 접근한다. (getter,setter)

- 상속
기존 클래스의 내용을 물려받는 기능(필드,메서드)
									
- 다형성
하나의 타입으로 여러 객체를 다룰 수 있는 성질
타이어마다 성능이 다르다.

- 추상화
클래스를 단순화시키는 것

메서드 내부에서 메서드를 정의할 수 없다.
메서드 외부에서 메서드를 호출하는 것은 불가능하다.

- 메서드
접근제한자 반환타입 메서드명(매개변수) {}

return
매개변수,메서드 내부에서 정의된 변수는 지역변수이다.
메서드가 호출되서 실행한 다음 종료가 되면 메모리에서 삭제된다.

만약 메서드 밖에서 연산결과를 사용하고 싶다면 return을 통해 값을 밖으로 꺼내야한다.

메서드명
- 메서드를 호출할 때 사용하는 이름
- 첫글자는 소문자로 작성

사용자가 직접 정의하면 컴파일러가 만든 기본생성자는 사용되지 않는다.

메서드처럼 매개변수를 가질 수 있다.

오버로딩(overloading)
- 같은 이름으로 서로 다른 개수,타입의 매개변수를 각각 처리하는 방법

- 반환형은 달라도 상관없음
- 메서드(or 생성자)명은 같아야 함
- 매개변수의 개수가 다르거나, 타입이 다르거나, 순서가 달라야함.

접근제한자 (Access Modifier)
public : 프로젝트 내에서는 어디서든지 사용 가능
default : 같은 패키지 내의 다른 클래스 어디서든지 사용가능
private : 현재 클래스에서만 사용 가능
protected : 같은 패키지와, 상속한 자식 클래스가 사용 가능
