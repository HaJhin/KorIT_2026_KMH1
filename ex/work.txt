A회사는 다음과 같은 시스템을 구축하려고 한다.

사용자가 동시에 접속하는 온라인 쇼핑몰
하루 수천 건의 이미지 업로드 처리
24시간 운영 서버
회원정보와 주문정보 저장
보안이 중요한 결제 시스템 포함

회사는 운영체제 선정과 시스템 요구사항 분석을 진행하고 있다.

문제 1. 운영체제의 역할 설명하기

운영체제(OS)의 역할을 설명하고, 운영체제가 없는 경우 어떤 문제가 발생하는지 작성하시오.

컴퓨터의 하드웨어와 소프트웨어 자원을 관리하고, 프로그램이 실행될 수 있도록 공통 서비스를 제공하는 소프트웨어
컴퓨터와 프로그램 사이에서 중간 관리자 역할을 하는 소프트웨어이다.

문제 2. 운영체제 종류 구분하기

다음 운영체제의 특징을 작성하시오.

Windows : 마이크로소프트의 유료 OS. 가장 대표적으로 널리 쓰이는 OS.
Linux : 무료 오픈소스 OS. 개발자들이 즐겨 사용한다.
UNIX : 서버 등 대형 시스템에 주로 쓰이는 유료 OS. 안정적이나 가격이 비싸다.


문제 3. 신뢰도 요구사항 분석하기

온라인 쇼핑몰 서버는 24시간 운영되어야 한다.
운영체제 선정 시 신뢰도가 중요한 이유를 작성하시오.

장시간 멈추지 않고 계속 돌아가야하는 서버는 운영체제의 불안정으로 인해 작동이 멈출 시
다방면에서 큰 손실을 안겨줄 수 있다. 그렇기에 빠르고 안정적인, 신뢰도가 높은 OS를 선정하는 것이 중요하다.

문제 4. 메모리 누수 설명하기

메모리 누수(Memory Leak)의 개념과 문제점을 작성하시오.

메모리 누수 : 프로그램이 사용한 메모리를 다시 반납하지 않는 문제이다.
메모리 누수가 발생할 시 서버의 성능이 저하된다.

문제 5. 동시 사용자 처리 분석하기

수강신청 시스템에서 오전 9시에 학생 5,000명이 동시에 접속하였다.
운영체제가 처리해야 하는 작업을 작성하시오.
1. 누가 먼저 처리될지 결정
2. cpu 사용 분배
3. 메모리 할당
4. 네트워크 연결 관리
5. 프로세스 스케쥴링

문제 6. 대용량 파일 처리 요구사항 분석하기

영상 업로드 서비스에서 운영체제의 파일 처리 성능이 중요한 이유를 작성하시오.

여러 사용자가 동시에 영상을 업로드 할 시 디스크 사용량이 급증한다.
이때 파일 처리 성능이 좋지 않으면 파일 처리 속도가 길어지고 이는 서버 성능 저하로 이어진다.

문제 7. 32bit 운영체제와 64bit 운영체제의 차이점을 작성하시오.

운영 체제가 얼마나 많은 메모리를 사용할 수 있는지를 의미한다.
32bit는 최대 4GB, 64bit는 4GM 이상의 메모리를 사용할 수 있다.

문제 8. 운영체제 선정 시 공급 벤더의 기술 지원이 중요한 이유를 작성하시오.

서버를 운영하다보면 이런저런 문제가 발생할 수 있는데, 이때 공급업체가 해결 방법을 지원해야 한다.

문제 9. 사용자가 많은 운영체제를 사용하는 장점을 작성하시오.

문제가 발생했을때, 비슷한 문제를 겪은 사람이 많기에 해결 방법을 쉽게 찾을 수 있다.

문제 10. Linux가 서버 환경에서 많이 사용되는 이유를 작성하시오.

무료 운영 체제이기에 서버 수가 많을 수록 비용 절감 효과를 누릴 수 있다.

문제 11. 운영체제에서 드라이버가 필요한 이유를 작성하시오.

운영체제가 주변 기기와 대화하기 위한 프로그램으로, 드라이버가 없을 시 OS가 기기를 인식하지 못한다.

문제 12. Linux 서버가 저사양 서버에서도 많이 사용되는 이유를 작성하시오.

GUI 없이 CLI 만으로도 운영이 가능하여 메모리 사용량이 적다 -> 저사양 서버에서도 운영이 가능하다.

문제 13. 다음 환경에서 비용 절감 효과가 큰 이유를 작성하시오.

1. 운영체제 역할 설명하기
- 하드웨어, 소프트웨어 자원을 관리한다.
- CPU, 메모리, 디스크 등을 프로그램에 할당한다.
- 사용자와 컴퓨터 사이의 중간관리자 역할을 수행한다.
없는 경우 발생할 수 있는 문제
- 프로그램 실행이 어렵다.
- CPU와 메모리를 직접제어해야한다.
- 여러 프로그램을 동시에 실행하기 어렵다.

2. 운영체제의 종류 구분
WINDOWS
- 개인용, 중소규모 서버에 많이 사용된다.
- GUI를 사용한다.
LINUX
- 무료 오픈소스
- 서버 환경에서 많이 사용됨
UNIX
- 안정성이 높고 대규모 서버 환경에 사용한다.

3. 신뢰도 요구사항 분석

- 서버는 장기간 안정적으로 동작해야한다.
- 운영체제 발생 가능성을 줄여야 한다.
- 메모리 누수 발생 시 성능 저하가 발생할 수 있다.
- 보안 패치 및 버그 수정 시 안정적인 운영이 필요하다.
- 서버 중단 시 결제 오류와 서비스 장애 발생 가능

4. 메모리 누수

개념
- 프로그램이 사용한 메모리를 반납하지 않는 현상
문제점
- 메모리 사용량이 증가한다.
- 서버 속도가 느려진다.
- 프로그램 오류가 발생할 수 있다.
- 결국 서버를 재기동할 필요가 있다.

5. 동시 사용자 처리 분석

- CPU 사용량 분배
- 메모리 할당
- 네트워크 연결 관리
- 프로세스 스케쥴링
- 사용자 요청 처리 순서 결정

6. 대용량 파일처리 요구사항 분석

대용량 파일 저장 작업이 많기 때문에 디스크 I/O 성능이 중요하다.
여러 사용자가 동시에 업로드할 수 있다.
파일 저장속도가 느리면 서비스 성능이 저하된다.
서버 과부하가 발생할 수 있다.

7. 32/64bit 운영체제 차이점

32bit
메모리 사용 4GB 제한
64bit
메모리 4GB 이상 사용 가능

8. 운영체제 선정 시 공급 배너의 기술 지원이 중요한 이유

- 장애 발생 시 빠른 대응이 가능하다.
- 보안 패치를 안정적으로 받을 수 있다.
- 공식 문서와 메뉴얼을 받을 수 있다.
- 유지 보수가 쉬워진다.
- 장기 지원 버전을 사용할 수 있다.

9. 사용자가 많은 운영체제를 사용하는 장점

- 검색 자료가 많다.
- 문제 해결 방법을 쉽게 찾을 수 있다.
- 커뮤니티 활동이 활발하다.
- 예제 코드와 기술 문서가 풍부하다.
- 유지보수 인력을 구하기 쉽다.

10. Linux가 서버 환경에서 많이 사용되는 이유

- 무료 오픈소스
- 자유로운 수정이 가능하며 서버 환경에 최적화

11. 운영체제에 드라이버가 필요한 이유

- 운영 체제와 주변기기 사이를 연결해준다.
- 운영체제가 장치를 인식할 수 있게 해준다.
- 프린터, 웹캠 그래픽 카드 등을 사용할 수 있게 해준다.

12. 리눅스 저사양 서버에서도 많이 사용되는 이유

- CLI 환경으로 운영이 가능
- 메모리 사용량이 적다
- 하드웨어 요구사항이 상대적으로 낮다.
- 서버 비축 비용을 절감할 수 있다.

13. 다음 환경에서 비용절감 효과가 큰 이유
