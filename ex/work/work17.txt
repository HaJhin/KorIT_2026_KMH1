다음 내용을 모두 포함하여 작성하시오.

또한 오류 상황 운영을 운영 DB에서 테스트하면 운영 서비스가 중단되거나 무결성이 훼손될 수 있다.

테스트 환경 구축 시 준비해야 하는 항목을 6가지 작성하시오.
1. Adapter 설치
2. 연계 서버 설정
3. 테스트용 DB와 테스트용 테이블 설정
4. 테스트용 파일 경로 설정
5. 네트워크 설정
6. 방화벽 및 포트 설정

테스트 환경은 운영 환경과 어떻게 구성해야 하는지 작성하시오.
- 운영환경과 유사하게 구성한다.
운영체제,DBMS,네트워크,서버 사양,보안 정책,연계 솔루션 버전,데이터 규모 등을 운영환경과 비슷하게 구성해야 한다.
환경이 차이가 크면 테스트에서는 정상적으로 동작해도 운영 환경에서 성능 저하나 호환성 오류가 발생할 수 있다.

문제 5. 정상 시나리오와 비정상 시나리오
시나리오

프로젝트 팀장은 정상적인 데이터뿐 아니라 오류 상황도 반드시 테스트하도록 지시하였다.

조건

다음 내용을 모두 포함하여 작성하시오.

정상 시나리오 테스트 4가지를 작성하시오.
- 정상적인 회원 데이터가 수신 시스템으로 전송되는지 확인
- 회원 코드가 약속된 코드로 정상적으로 매핑되는지 확인
- 수신된 회원 데이터가 수신 DB에 정상적으로 반영되는지 확인
- 전송 시작 시간, 완료 시간, 처리 결과가 로그에 정상적으로 기록되는지 확인

- 네트워크 장애를 발생시켜 오류 처리와 재전송 여부 확인
- DB Lock을 발생시켜 대기, 오류 기록 또는 재전송 여부 확인
- 연계 서버를 중지하여 관리자 알림과 복구 후 재전송 여부 확인
- 회원 번호나 이름같은 필수 값을 누락하여 오류 처리 여부 확인
- 허용된 길이를 초과하는 데이터를 전송하여 오류 처리 여부 확인

비정상 시나리오 테스트가 필요한 이유를 작성하시오.
- 실제 운영 중 발생할 수 있는 장애와 잘못된 데이터에 시스템이 정상적으로 대응하는지 확인하기 위해 필요하다.
오류가 발생했을 때 로그 기록, 오류 코드 반환, 관리자 알림, 재처리, 롤백 등이 제대로 수행되지 않으면 데이터가 누락되거나 중복, 업무가 중단될 수 있다.
