제네릭 : 프로그래밍에서 데이터의 타입을 일반화시키는 기법을 말한다.
타입 안정성의 향상, 불필요한 형변환 제거, 코드 재사용성 증가를 위해 사용한다.
제네릭 클래스와 제네릭 메서드의 차이점 : 
제네릭 클래스 : 클래스 옆에 타입 파라미터가 정의된 클래스.
객체를 생성할때 타입이 결정되며 필드 변수, 매개 변수, 반환 타입등 여러곳에서 사용 가능하다.
제네릭 메서드 : 메서드의 선언부에 타입 파라미터가 정의된 클래스.
메서드를 호출할때 타입이 결정되며, 정적 메서드에서도 제네릭을 사용할 수 있게 해줌
제네릭을 사용하지 않으면 타입 안정성이 없어져 아무런 데이터나 컬렉션에 넣을 수 있게 되고, 그 때문에 일일히 번거로운 형변환을 해줘야 하며, 프로그램 사용 중 런타임에러가 발생할 수 있다는 문제점이 있다.

List,Set,Map
자바 컬렉션 프레임 워크의 핵심.
List : 데이터를 넣은 순서를 유지하며, 중복된 데이터를 허용하는 컬렉션. 인덱스를 통해 데이터에 접근 가능. 대표 클래스 : ArrayList
Set : 중복된 데이터를 허용하지 않고, 데이터의 순서를 보장하지 않는다.
대표 클래스 : HashSet
Map : key와 value를 쌍으로 저장하는 클래스. key는 중복 불가능, value는 중복 가능.
key값을 통해 value를 빠르게 찾을 수 있다.
대표클래스 : HashMap

람다식
이름이 없는 익명함수를 뜻한다.
데이터 병렬 처리와 코드의 간결성을 중요시 하게 되면서 함수형 프로그래밍이 유행하자
도입하게 되었다.
함수형 인터페이스란 단 하나의 추상 메서드만 정의된 인터페이스를 말한다.
람다식을 사용하기 위해선 메서드를 담을 틀이 필요한데, 그 틀 역할을 함수형 인터페이스가
수행한다.
기존 익명 클래스 방식보다 문법이 간결해지고, 호출 시 마다 객체를 생성하는 익명클래스와 다르게 클래스를 만들지 않고 메서드 호출 방식으로 동작하여 효율적이다.
람다식을 사용할 시 코드를 매우 간결하게 작성할 수 있고, 결과가 필요할때까지 계산을 미뤄 효율적인 리소스 사용을 가능하게 하는 지연 연산이 가능하며, 메서드를 다른 메서드의 인자값으로 전달할 수 있어 코드의 재사용성과 유연성이 증가한다.
