src 폴더
- 소스코드가 저장되는 폴더
- 패키지 단위로 폴더가 만들어지고, 그 안에 파일이 위치한다.
- 작성하는 모든 파일은 이곳에 저장된다.
JRE System Library
- 프로젝트 실행에 필요한 코드들의 묶음
- 기본적인 기능이 들어있다.
- 프로젝트 생성 시 자동으로 추가된다.
Package
- 관련있는 클래스끼리 묶어놓는 폴더 개념
- src 폴더 안에 하위 폴더로 생성됨.
Class
- 자바 프로그램의 기본 구성 단위이다.
- 자바에서 모든 코드는 반드시 클래스 블록( {} ) 안에 있어야 한다.
Method
- 클래스 안에서 정의된 함수

정수 -> 문자
실수를 정수로 바꿀 때 소수점 아래 값은 소실된다.
자바코드 -> 바이트코드 -> JVM이 실행 -> 결과가 출력

자바는 실행성능을 향상 시키기 위해 컴파일 과정을 거친다.

형변환(타입변환)
자동형변환(묵시적형변환)
작은 자료형에서 큰 자료형으로 바꿀때
정수->실수, 문자->정수
강제형변환(명시적형변환)
(원하는 자료형)데이터 or 변수
큰 자료형에서 작은 자료형으로 바꿀때
실수->정수, 정수->문자

데이터의 입력
java.util에 있는 Scanner 클래스를 사용한다.

import
- 다른 패키지에 있는 클래스를 사용하겠다고 명시하는 것

import java.util.Scanner;
- 클래스 안에는 함수(기능)가 정의되어 있다.
- 클래스 안에 정의된 메서드를 사용하기 위해서는 객체를 생성해야한다.
객체를 생성하는 방법
(클래스명) (객체명) = new 클래스명();
Scanner scan = new Scanner(System.in);
System.in -> 키보드 입력을 받는 기본통로
만들어진 객체를 통해서 클래스 안에 정의되어있는 메서드를 호출할 수 있다.

sc.메서드명();

삼항연산자

제어문,조건문
-조건에 따라 실행할 명령을 결정한다.

제어문(코드의 흐름을 제어하는 문법)
-기본적인 코드의 흐름
위에서 아래로, 좌에서 우로 동작한다. (대입 연산자는 오른쪽에서 왼쪽으로 동작)

조건식 : 연산의 결과가 true 또는 false로 반환되는 식
(비교연산자, 논리연산자)

조건문(분기문)
조건에 따라 실행할 명령을 결정하는 문법

switch문(값을 1대1로 비교할때)
- 비교값과 일치하는 조건값의 case로 접근하여 바로 실행

객체지향 프로그래밍(object-oriented Programming)
- 프로그램을 객체 단위로 나눠 설계하고 구현하는 방식		

객체지향을 사용하지 않을 때 문제점
- 데이터와 기능이 따로 논다
- 코드가 많아지게 되면 관리가 어렵다
- 재사용이 힘들다

객체지향의 핵심 개념
1. 클래스
-설계도
- 필드
ㄴ 객체의 정보
메서드
ㄴ 객체의 동작		

2. 객체
클래스명 객체변수명 = new 클래스명();
객체변수명.필드명
- 클래스에 정의된 기능을 호출하여 사용 가능

3. 객체지향의 4가지 개념
- 캡슐화
데이터를 보호하는 개념
필드에 직접 접근하지 못하도록 만든다.
제공된 메서드를 통해 필드에 접근한다. (getter,setter)

- 상속
기존 클래스의 내용을 물려받는 기능(필드,메서드)
									
- 다형성
하나의 타입으로 여러 객체를 다룰 수 있는 성질
타이어마다 성능이 다르다.

- 추상화
클래스를 단순화시키는 것

메서드 내부에서 메서드를 정의할 수 없다.
메서드 외부에서 메서드를 호출하는 것은 불가능하다.
