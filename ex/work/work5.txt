시나리오
한 학원에서 수강생,과정,강사 정보를 하나의 테이블로 관리하고 있다.

수강번호   수강생명   전화번호   과정코드   과정명   강사번호   강사명   강사연락처   교재명
1001   김철수   010-1111-1111   C001   Java 기초   	T01   		이영희   010-5555-1111   Java 입문
1001   김철수   010-1111-1111   C002   Spring   	T02   		박민수   010-5555-2222   Spring 기본
1002   이수진   010-2222-2222   C001   Java 기초   	T01   		이영희   010-5555-1111   Java 입문
1003   박영수   010-3333-3333   C003   React   	T03   		김미영   010-5555-3333   React 실전

조건
기본키 : (수강번호,과정코드)
정규화 과정은 1차 -> 2차 -> 3차로 진행한다.
3. 각 단계마다 결과 테이블 작성
4. 각 테이블에 PK를 표시한다.
5. 3차 정규화 완료 후 최종 테이블 관계를 작성한다.

문제 1
현재 테이블이 1차 정규형을 만족하는지 작성하고 그 이유를 설명

답 : 만족함(이유 : 모든 속성이 원자값으로 이루어져 있으며 한 칸에 여러 값이 저장되어있지 않다.)

문제 2 
현재 테이블에서 2차 정규화 수행

수강생

속성 : 수강번호,수강생명,전화번호

과정
PK : 과정코드
속성 : 과정코드,과정명,강사번호,강사명,강사연락처,교재명

문제 3
2차 정규화된 테이블에서 3차 정규화 실행

과정
PK : 과정코드
속성 : 과정코드,과정명,강사번호,교재명

강사

속성 : 강사번호,강사명,강사연락처
