문제

A회사는 ERP와 CRM을 연계하여 회원 정보를 전송하고 있다.

다음과 같은 상황이 발생하였다.

ERP 서버 : 정상
네트워크 : 정상
CRM 서버 : 정상
회원 등록 중 다음 오류가 발생하였다.
오류코드 : EAD001

등록된 회원이 이미 존재합니다.
조건

다음 내용을 작성하시오.

연계 오류의 유형 : 연계 데이터 오류
오류의 원인 : 중복 데이터로 인한 데이터 등록 실패
해결 방안 : DB에 등록되지 않은 데이터로 재등록
해결 후 확인해야 하는 사항 2가지
1. DB에 데이터가 정상적으로 등록되었는지
2. 연계 모니터링/로그 상태가 정상으로 변경되었는지

문제

쇼핑몰 주문 시스템에서 주문 데이터를 물류 시스템으로 전송하고 있다.

현재 송신 시스템은 JSON 형식으로 데이터를 전송하고 있으며, 물류 시스템은 XML 형식만 처리할 수 있다.

로그에는 다음과 같은 메시지가 출력되었다.

JSON → XML 변환 실패
조건

다음 내용을 작성하시오.

오류 유형 : 연계 프로그램 오류
오류 원인 : XML만 처리 가능한 시스템에 JSON 형식의 데이터를 보냈기 때문에
해결 방안 : 물류 시스템이 JSON 형식의 데이터로 처리할 수 있도록 개선한다
적용해야 하는 작업 : 물류 시스템의 프로그램 로직 수정
해결 여부 확인 방법 : JSON 형식의 데이터를 시스템에 전송해 로그에서 에러가 나지 않는지 확인한다.

문제

ERP에서는 사용자 권한을 다음과 같이 관리한다.

SUPER

CRM에서는 다음 코드만 등록되어 있다.

ADMIN

연계 프로그램을 실행한 결과 다음 오류가 발생하였다.

오류코드 : EAC001

등록된 코드가 없습니다.
조건

다음 내용을 작성하시오.

오류가 발생한 이유 : 연계 데이터 오류
해결 방법 : 	CRM에 SUPER코드를 등록한다.
동일한 문제가 다시 발생하지 않도록 예방 관리 방법 2가지를 작성하시오.

예약 데이터는 정상적으로 전송되었다.
진료 시스템 DB에는 데이터가 저장되지 않았다.
로그에는 다음 내용이 기록되었다.
오류코드 : EAD001

PK 중복
조건

오류 식별 방법 : 오류코드가 무엇인지 확인한다.
오류 원인 분석 방법 : 전송하려는 데이터가 이미 DB에 존재하는지 확인한다.

2. 오류 코드 및 메시지
3. 오류 원인
4. 조치 내용 및 해결 방안

문제

ERP와 CRM을 연계하여 고객 정보를 전송하고 있다.

다음과 같은 상황이 발생하였다.

송신 프로그램 : 정상
데이터 : 정상
연계 서버 : 정상
방화벽 정책 변경으로 Port가 차단되었다.
고객 정보가 CRM으로 전달되지 않았다.
조건

다음 내용을 작성하시오.

오류 유형 : 연계 시스템 오류
오류 원인 : Port가 차단되어 CRM으로 정보 전송 실패
해결 방안 : 방화벽 관리 부서에 연계에 사용되는 포트의 오픈을 요청하여 방화벽 정책 재설정
해결 후 확인해야 하는 사항 3가지
1. 포트 통신 상태 확인
2. 누락 데이터 재전송 및 CRM DB 등록 여부 확인
3. 연계 모니터링 로그 및 상태 정상화 확인
동일한 문제가 다시 발생하지 않도록 예방 관리 방법 2가지를 작성하시오.
1. 방화벽 정책 및 네트워크 변경 관리 절차 수립
2. 연계 포트 통신 상태 상시 모니터링 구축
