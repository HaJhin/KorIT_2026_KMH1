문제 3. 모든 예약 정보 조회

데이터베이스에 저장된 모든 진료 예약 정보를 조회하는 기능을 구현하세요.

요청 방식은 다음과 같습니다.

GET /reservations

DAO 조건

ReservationDAO에 다음 메서드를 작성하세요.

List<ReservationVO> findAll();

DAO 조건

ReservationDAO에 다음 메서드를 작성하세요.

List<ReservationVO> findAll();

DAO는 MyBatis Mapper와 연결되도록 작성합니다.

Mapper XML 조건

Mapper XML에 다음 SQL을 작성하세요.

SELECT *
FROM reservation

Mapper의 namespace는 DAO 클래스의 전체 경로와 일치해야 합니다.

예:

<mapper namespace="com.korea.petclinic.dao.ReservationDAO">
Service 조건

DAO의 findAll() 메서드를 호출하여 결과를 Controller에게 반환합니다.

Controller 조건

다음 주소로 요청을 받습니다.

GET /reservations

조회 결과를 JSON으로 반환합니다.

문제 4. 특정 예약 조회

예약 번호 id를 이용하여 하나의 예약 정보를 조회하세요.

요청 예시:

GET /reservations/1

DAO에 다음 메서드를 작성합니다.

ReservationVO findById(Long id);

Mapper XML에서 다음 조건을 사용합니다.

WHERE id = #{id}

PathVariable을 이용하여 URL에서 id 값을 전달받으세요.
